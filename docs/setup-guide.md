# TrustLedger — Local Setup & Execution Guide

This guide walks you through setting up, deploying, and running **TrustLedger** completely on your local development machine without requiring paid services, testnet faucets, or external cloud infrastructure.

---

## 1. Prerequisites

- **Node.js**: LTS version (v18, v20, v22, or v24). Check with `node -v`.
- **npm**: v9 or higher. Check with `npm -v`.
- **MetaMask Extension**: Installed in Chrome, Brave, Edge, or Firefox browser.

---

## 3. Step-by-Step Execution Order

Follow these terminal commands in order.

### Terminal 1: Compile, Test, and Launch Local Blockchain

```bash
# 1. Install root dependencies (if not already installed)
npm install

# 2. Compile the smart contract
npx hardhat compile

# 3. Run automated smart contract unit tests
npx hardhat test

# 4. Start the local Ethereum development node
npx hardhat node
```

> **Note:** Keep Terminal 1 running. The `npx hardhat node` process runs the local Ethereum node at `http://127.0.0.1:8545` with 20 pre-funded test accounts containing 10,000 ETH each.

---

### Terminal 2: Deploy Contract to Local Node

In a new terminal window at the project root:

```bash
# Deploy to local network and generate frontend config
npx hardhat run scripts/deploy.js --network localhost
```

### Terminal 3: Launch the React Frontend

In another terminal window:

```bash
cd frontend

# Install frontend dependencies (if not already installed)
npm install

# Start Vite development server
npm run dev
```

Open your browser to the URL displayed (typically `http://localhost:5173`).

## 4. MetaMask Wallet Configuration

To interact with TrustLedger, connect MetaMask to the local Hardhat blockchain:

### Step 1: Add Custom Local Network

1. Open MetaMask and click on the **Network Selector** dropdown in the top left.
2. Select **Add Network** → **Add a network manually**.
3. Enter the following parameters:
   - **Network Name:** `Hardhat Local`
   - **New RPC URL:** `http://127.0.0.1:8545`
   - **Chain ID:** `31337`
   - **Currency Symbol:** `ETH`
4. Click **Save** and switch to `Hardhat Local`.

### Step 2: Import Local Development Accounts

Import the first two development accounts generated by `npx hardhat node`:

- **Account #0 (Platform Administrator):**
  - Address: `0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266`
  - Private Key: `0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80`
  *(Used to verify campaigns)*

- **Account #1 (Campaign Creator / Donor):**

## 5. End-to-End Verification Walkthrough

1. **Inspect Seeded Campaigns:**
   - On the homepage, view the pre-seeded demonstration campaigns. Notice that Campaign #1 & #2 display the green `Verified by Admin` badge, while Campaign #3 displays `Pending Admin Verification`.
2. **Connect Wallet:**
   - Click **Connect Wallet** in the top navigation bar. Switch to Account #0 to test administrator capabilities.
3. **Admin Verification:**
   - Open Campaign #3 ("Community Digital Learning Center").
   - Click **Verify Campaign Now**. Confirm the transaction in MetaMask.
   - Notice the status immediately updates to `Verified by Admin`, unlocking the donation box.
4. **Make a Donation:**
   - Switch in MetaMask to Account #1 (Donor).
   - In Campaign #1 or #2, enter `0.5` ETH and click **Confirm Donation**.
   - Approve the transaction.
   - Observe that the amount raised, progress percentage bar, and on-chain donation ledger update immediately.
5. **Withdrawal:**
   - When a campaign reaches 100% of its funding goal, connect with the creator's wallet.
   - The green **Withdraw Funds** banner will appear. Confirm the transaction to release funds to the creator.
